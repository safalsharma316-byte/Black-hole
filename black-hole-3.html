Equations used in this model

Units: Schwarzschild radius Rs = 1 (M = ½). Same formulas as in the shader code.

1 · Black hole geometry

Rs = 2GM / c² (Rs = 1)

Event horizon: ray with r < 1 is absorbed (black).

r_photon = 1.5 Rs

Photon sphere: light orbits here (thin bright ring).

r_ISCO = 3 Rs

Innermost stable orbit: inner edge of the disk.

2 · Light bending (ray tracing)

h = | r × v | (conserved) a = −1.5 · h² · r / |r|⁵

Schwarzschild null geodesic in Cartesian form, used instead of straight rays.

v ← v + a·dt r ← r + v·dt dt = clamp(0.07·(|r| − 0.9), 0.012, 0.5)

Step-by-step integration with smaller steps near the hole.

3 · Accretion disk

t = y₀ / (y₀ − y₁) p = p₀ + t·(p₁ − p₀)

Where a ray crosses the disk plane (y = 0); disk spans 3 < r < 11 (14 in Cinematic).

Ω(r) = 0.9 / r^1.5 φ = atan2(z, x) + 1.5·T·Ω

Keplerian rotation: inner gas spins faster.

I = 5 · (3/r)^2.2 · (1 − √(3/r)) · texture

Brightness (Interstellar / Cinematic). EHT: I = 3 · (3/r)^1.3 · (1 − √(3/r)).

4 · Doppler beaming

β = √(0.5 / (r − 0.8)) · ( t̂ · (−v̂) ) t̂ = (−z, 0, x)

Orbital speed toward the viewer, as a fraction of light speed.

D = 1 / (1 − β)
EHT: e = I · D⁴ · 0.9 Cinematic: e = I · D^2.2 · 1.1 Interstellar: I · 3 · (1 + 0.5(D − 1))

Approaching side gets brighter, receding side dimmer.

5 · Image

col += (1 − α)·c·a α += (1 − α)·a

Alpha blending of the disk layers (a ≈ 0.85–0.97).

out = (1 − e^(−1.3·col))^0.9

Tone mapping + gamma. Blur is a CSS Gaussian blur.

Simplified: non-spinning (Schwarzschild) black hole. The real Gargantua uses spinning Kerr geometry.
